Act as a Senior Backend Engineer with over 10 years of experience in designing secure, scalable, production-ready REST APIs and backend architectures.

Your task is to build the complete backend for a restaurant web application named "Mahadev Pizza Point".

The backend should follow clean architecture, SOLID principles, RESTful API standards, and production-level coding practices.
